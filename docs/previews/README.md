# Historical design references

The images in this directory are captures from the earlier native iOS Bloom prototype. They are archived visual references only; they are not screenshots of the Flutter Android app and are not a functional specification.

Use them only for broad inspiration such as plant photography, calm hierarchy, concise care language, and the distinction between a scheduled check and a recorded outcome. The Android UI, navigation, controls, accessibility behavior, and shipped feature scope are defined by:

- [`../STATUS.md`](../STATUS.md) — current implementation and verification.
- [`../PRD.md`](../PRD.md) — product contract and roadmap.
- [`../DESIGN_GUIDELINES.md`](../DESIGN_GUIDELINES.md) — Android/Flutter design rules.

Several captures show prototype features that are intentionally not in the Android watering baseline, including observations, care plans, environmental preferences, unlisted plants, and symptom guidance. Do not use those screens as evidence that those features exist in this repository.

The files are retained to preserve design history and case-study context. If a screenshot conflicts with current code or documentation, current code and `docs/STATUS.md` win.
